# V3.27 跨市场时段感知与交易界面说明

## 目标

V3.27 解决两个容易导致错误判断的问题：不同国家市场开盘时间不同，以及高度相关指数被重复计权。同时修复 K 线缓存不完整、异常标注压图、实盘账户缺失被误显示为零等界面问题。

## 跨市场时间规则

系统不把所有海外报价视为同一种“实时行情”，每条证据都记录来源时间、当前阶段、新鲜度和是否进入评分：

- 港股现金盘按香港本地交易时段判断，午休不当作连续交易；
- 日本和韩国市场按各自本地交易日及时段判断；
- 美国现金指数按美东时区判断盘前、正常交易、盘后和休市；
- 纳指、标普等期货根据源时间和新鲜度判断，不因现金盘休市就自动视为前收盘；
- 闭市且仍在有效窗口内的数据标为“前收盘参考”，权重低于正在交易的数据；
- 时间戳缺失、缓存过期或来源错误的数据不进入自动买入评分。

交易时段依据以交易所公开规则为准：HKEX 现金市场包含上午、下午及收市竞价阶段；Nasdaq 正常交易为美东 09:30-16:00；KRX 正常交易为韩国时间 09:00-15:30。节假日和临时休市仍由市场日历与数据新鲜度共同判断，不能只依赖工作日。

## 相关性去重

海外科技风险先按资产家族聚合，再进入大盘环境：

1. 美国科技：纳斯达克 100、纳斯达克综合、纳指期货、费城半导体。
2. 美国宽基：标普期货、道琼斯等。
3. 大中华科技：恒生科技等。
4. 日本和韩国：日经、韩国综合等。

同一资产家族只保留质量和时效更高的代表证据，并对美国科技、大中华科技、日本/韩国设置家族权重上限。这样可以利用不同市场的先后开盘关系，又不会把同一轮全球科技涨跌重复计算多次。

## 评分边界

- 全球情绪以 50 分为中性，根据有效证据涨跌、时效和阶段权重有限偏移。
- 进入大盘环境时，国内市场证据占 85%，有效全球环境最多占 15%。
- 至少需要两个去相关资产家族、一个直接科技证据和一个交易中证据才视为有效全球环境。
- 全球环境只调整市场状态和仓位倾向，不直接替代个股技术、基本面、信息面和资金面判断。
- 数据不足、过期或质量不合格时显示缺失原因，并保持中性。
- 历史回测不使用当前全球行情。没有 point-in-time 海外快照时，历史日期的全球维度显示缺失，而不是回填今天的数据。

## 模块结合

- 筛选：全球环境只作为大盘背景；个股仍由既有评分、策略适配和风险标签决定排序。
- 实时模拟：每轮决策从同一缓存读取全球环境，写入评分溯源；过期数据不能触发新增仓位。
- 实盘：决策观察页只读取行情、已保存评分、持仓和账户同步结果。任何真实订单仍需交易时段、数据新鲜度、风控、白名单、人工确认和券商连接全部通过。
- 回测：仅使用历史 K 线和当时可得的快照，不允许未来数据泄漏。
- 信息事件：央行、就业、交割、财报窗口、指数调仓、解禁、减持、地缘和供应链事件记录影响窗口、传导链及风险门禁；未知结果的未来事件不预设利多或利空。

## 页面与图表

- `/auto-trading` 显示全球科技环境、板块主线、模块状态和统一入口。
- `/live-trading` 显示多股票价格、买一卖一、评分、阻断原因、持仓成本和盈亏；券商未连接时账户字段显示 `--` 及缺失原因。
- 日 K/周 K/月 K 支持平移查看；分时保持固定交易时间轴。
- K 线异常标注在主图上只显示短标记，完整说明进入独立面板；标注价格不再拉伸 K 线价格轴。
- K 线请求会检查缓存根数，短缓存不足时自动补齐，避免 520 根请求只显示几十根。

## API

- `GET /api/market/global-sentiment`
- `GET /api/market/regime`
- `GET /api/score/latest/{symbol}`
- `GET /api/live-broker/status`
- `GET /api/live/account`
- `GET /api/live/positions`

`/api/market/global-sentiment` 返回综合分、有效性、交易阶段、证据、去重排除项、家族覆盖、来源状态、缺失原因和更新时间，可用于前端解释和审计。

## 安全与真实性

- `FEATURE_LIVE_BROKER=false`、`LIVE_TRADING_ENABLED=false`、`ORDER_CONFIRM_REQUIRED=true` 保持默认值。
- QMT/PTrade SDK、环境变量、账号授权任一缺失时返回 disabled 或 unsupported。
- 未连接真实账户时不生成虚假现金、持仓、委托或成交。
- 百度、360、搜狗搜索结果页永久禁用；新闻和事件必须保留可追溯来源。
- 联网智能辅助只解释有效证据，不能创建、批准或提交订单。
