# V3.28 单包迁移与缺漏审计

## 结论

- 当前唯一运行包为 `D:\电脑管家迁移文件\quant_data_gateway_v3_26_system_rebuild`。
- 旧 V3.16 提交是当前 V3.28 分支的祖先；从旧基线到当前版本共有 163 个文件变更，新增 48 个、修改 72 个、完整重命名 43 个，没有整文件删除。
- 新版功能代码覆盖旧版，并新增自动交易总控台、统一评分与风控、实时模拟、券商接入、同花顺提醒、全球情绪、每日评分走势、交易记录和数据中心。
- 迁移前的主要缺漏不是代码，而是旧目录独有的本地 SQLite、新闻缓存、自选股和历史回测文件。

## Python 运行环境修复

项目迁移后，新目录没有旧项目的 `.venv`，Windows `PATH` 中也没有 `python` 命令。现已：

1. 新建项目 `.venv`；
2. 补充遗漏的 `lxml` 运行依赖；
3. 新增 `python_runtime.bat`，依次使用项目 `.venv`、D 盘 Python、Windows `py` 启动器、系统 Python 和 Codex 运行时；
4. 所有启动脚本改为通过统一运行时启动；
5. `install.bat` 改为安装完整依赖清单 `requirements_full.txt`。

- 测试数据库和旧日志没有迁入。
- 未发现旧项目中的 `.env`、券商账号、密码、令牌或 Cookie。
- 迁移前备份和机器可读迁移报告保存在新版 `data/migration_backups/`，该目录不提交 Git。
- 所有核心 SQLite 数据库在合并后均通过 `integrity_check=ok`。
