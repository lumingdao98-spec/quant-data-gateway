# V3.23 Compliance Notes

This project is research software. It is not investment advice and not a regulated trading service.

Users are responsible for:

- Broker authorization and local terminal setup.
- Trading compliance and risk suitability.
- Account, password and token security.
- Manual order confirmation when required.
- Losses, slippage, missed fills, rejected orders and data-source errors.

The default system state does not connect to a real broker and does not place real orders.
