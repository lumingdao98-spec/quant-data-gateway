# V3.5 / InfoFix V6 完整修复说明

本版在 V3.4 多源分时兜底基础上继续修复信息面、新闻情绪、标签解释、公司画像和成交量副图问题。

## 1. 分时成交量副图修复

- 对分时点按交易日分组，自动识别公开接口返回的“累计成交量/成交额”。
- 当字段绝大多数点单调递增且末值显著大于分钟差分时，后端统一转换为单分钟增量。
- 仍然不使用快照行情伪造分时线；无真实分钟数据时继续显示暂无真实分时。

## 2. 个股信息面源质量修复

- 搜索页不再用“利空/利好”等关键词结果直接作为个股结论。
- 对“去网页搜、相关搜索、股友灌水、target=_blank、乱码正文”等噪声标题做过滤。
- 官方公告、巨潮/交易所/公司公告/F10 等高可信来源优先；社区/股吧只作为舆情观察，不进入核心利多利空证据。
- 风险标签只在公告/高可信新闻语境下强化，避免把普通发帖和搜索聚合当实锤。

## 3. 标签和情绪修复

- 修复标签解释弹层 `getSelectedStrategies is not defined`，统一调用 `selectedStrategies()`。
- “持股人/投资者收益受损”等不再误打“业绩亏损”；“业绩亏损”必须出现在财报、净利润、预亏等语境中。
- 新闻情绪前端中文化显示：positive/negative/neutral 显示为 正面/负面/中性。
- 风险标签去重、HTML 转义，避免重复和不可读内容。

## 4. 乱码处理

- 正文抓取跳过 PDF/Word/Excel/二进制内容。
- 增加 apparent_encoding 和乱码检测，乱码正文不进入展示和摘要。

## 5. 全球/国内要闻

- 增加多渠道快讯：akshare 可用源、华尔街见闻公开快讯接口、财联社 Web 电报接口。
- 全球/国内要闻与个股新闻严格分开，不混入单只股票相关新闻。
- 缓存降为短缓存；`/api/news/global?force=true` 可强制刷新。

## 6. 公司画像

- 新增 `data/company_profile.sqlite` 持久化公司画像。
- 公司简介补充基础信息、管理层/人员变动候选接口、历史业绩字段、财务摘要、来源诊断。
- 公开源失败时优先返回历史画像，并标记 stale_fallback。

## 7. 验证

- `python -m compileall -q quant_data` 通过。
- `PYTHONPATH=. pytest -q` 通过。
