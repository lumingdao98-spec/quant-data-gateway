# V3.10 / InfoFix V11 基本面、消息面、全球商品要闻与量化框架补全版

本版在 V3.9 基础上继续保留所有功能：实时行情、分时兜底、K线、前复权回撤校正、技术指标知识库、分类策略选择器、信息面事件级去重、公司/ETF画像、全球/国内要闻和标签解释。

## 新增与完善

1. 新增 `FundamentalLibraryService`
   - 固化宏观经济、流动性、国际关联、行业分析、公司财务、估值、治理、风险识别等知识库。
   - 每个因子包含：公式、判断标准、应用场景、数据来源、使用限制。
   - 新增消息源可信度分层：官方披露、权威财经媒体/快讯、综合财经网站、社区舆情。

2. 新增接口
   - `/api/fundamental/library`
   - `/api/fundamental/library/by-category`
   - `/api/fundamental/event-map`

3. 接入金十/金十期货公开快讯尝试
   - 全球/国内要闻源新增“金十/金十期货快讯”。
   - 对原油、黄金、黑色、农副、金属、能化、OPEC、美债、美元、地缘风险等做宏观/商品事件识别。
   - 若金十公开接口结构变化或网络不可用，不造假数据，只在 `sources_status` 中记录诊断并继续使用华尔街见闻、财联社、AKShare等源。

4. 宏观/商品事件行业映射
   - 新增原油、黄金、降息降准、加息紧缩、出口管制、AI芯片、新能源、地产政策、军工低空、医药政策等映射规则。
   - 不直接把全球新闻判成个股利好利空，而是先映射到行业，再结合个股名称、行业线索和主营业务做“可能影响”提示。

5. 信息面面板增强
   - 显示基本面框架入口。
   - 显示宏观/商品事件映射证据。
   - 来源可信度说明加入金十、财联社、华尔街见闻等权威快讯层级。

6. 策略选择器新增分类和策略
   - 宏观/大势：宏观流动性框架、全球商品事件映射。
   - 基本面/财务：基本面质量、现金流含金量、治理与股东风险。
   - 消息面/事件驱动：消息来源可信度、事件驱动、政策行业映射。
   - 回测/风控/执行：回测约束、仓位与止损。

7. 量化框架查漏补缺
   - 明确纳入数据清洗、复权、手续费滑点、风险控制、仓位、最大回撤、夏普、VaR、参数优化、样本外验证、实盘部署等框架。
   - 仍不伪造 Level-2、逐笔成交、真实主力持仓和虚假单结论。

## 运行

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
run_app_auto.bat
```

打开：

```text
http://127.0.0.1:8000/screener
```

建议 Ctrl+F5 清理浏览器旧缓存。
