# V3.14 / InfoFix V15 实时要闻、事件去重、公司画像与回撤校验修复版

本版基于 `V3.13 / InfoFix V14 信息面抓取与前沿要闻评分重构版` 继续修复，重点不是报告，而是把信息面逻辑继续落到可运行代码中。

## 1. 信息面去重修复

### 已修复问题

此前类似以下内容会被拆成多条：

- 东方财富 F10：`天合光能：将于2026年05月21日召开2025年年度股东大会`
- 东方财富股吧：同一公告标题的转载/讨论
- 股吧页面整页 table 文本被抽成摘要，导致 `event_key` 不同

### 新逻辑

- 新增 `_canonical_event_text()`：清洗股吧 table、HTML 属性、阅读/评论/作者等噪声；
- 新增 `_dedup_fingerprint()`：标题级事件指纹；
- 重写 `_event_key()`：对股东大会、董事会、监事会、业绩说明会、财报、监管、减持、订单、分红、宏观快讯进行事件族归并；
- 重写 `_deduplicate()`：按 `event_key`、规范化标题和近似标题三层合并；
- 股吧只作为舆情和传闻风险，不再把整页表格当摘要。

验证用例：`tests/test_infofix_v15.py::test_shareholder_meeting_dedup_between_f10_and_guba`

## 2. 全球/国内/商品/政策要闻自动刷新

### 新增/增强来源

- 东方财富快讯：焦点、全球、中国、美国、外汇、商品、基金、股市直播；
- 金十/金十期货；
- 财联社电报；
- 华尔街见闻；
- AKShare 可选源。

### 新逻辑

- 全球要闻使用 45 秒短缓存；
- 前端每 60 秒自动刷新全球要闻模块；
- 个股公司/公告信息仍按主动刷新或缓存过期刷新；
- 全球要闻按 `国内宏观/A股市场`、`国际消息/全球市场`、`海外央行/全球利率`、`外汇债券/美元美债`、`大宗商品/原材料` 等拆分；
- 只有与公司主营、业务标签、产业链暴露匹配的全球要闻才进入信息面映射分。

## 3. 公司画像增强

新增字段：

- `business_tags`
- `main_products`
- `upstream`
- `downstream`
- `business_segments`
- `industry_exposure_text`

内置部分常见公司主营业务画像兜底，例如：

- 天合光能：光伏组件、太阳能电池片、储能、智慧能源；
- 宁德时代：动力电池、储能、电池材料、回收；
- 通威股份：高纯晶硅、太阳能电池、组件、农牧饲料；
- 隆基绿能、比亚迪、贵州茅台、五粮液、东方财富等。

这样全球要闻出现“光伏、硅料、组件、储能、关税、海外装机”等相关内容时，可以和天合光能、通威股份、隆基绿能等公司的信息面评分发生关联。

## 4. 信息面评分融合增强

本版继续使用三维融合思想：

```text
综合分 = 技术/量价底分 × (1 - 信息面权重) + 信息面分 × 信息面权重
```

信息面内部：

```text
信息面分 = 0.30×公司/公告事件
        + 0.10×来源可信度
        + 0.16×财报估值
        + 0.36×全球/国内要闻相关映射
        + 0.08×(100 - 传闻噪声)
        - 官方负面惩罚
```

关键变化：全球要闻实时刷新，但只有相关映射命中时才改变个股信息面分；无相关信息时不强行扰动个股评分。

## 5. 回撤率校验修复

新增字段：

- `drawdown250_high`
- `drawdown250_low`
- `drawdown_basis`

定义固定为：

```text
drawdown250 = current_last / max(high[-250:]) - 1
```

单位为 `%`，负值代表回撤。例如 `-30` 表示相对近 250 日高点回撤约 30%。默认筛选口径仍为 `qfq` 前复权，减少分红送转带来的假回撤。

新增接口：

```text
GET /api/technical/drawdown/verify/{symbol}?adjust=qfq&limit=260&force=false
```

用于核对回撤率的高点、低点、实时价和复权口径。
