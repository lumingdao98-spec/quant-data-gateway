# V3.15 / InfoFix V16.1 深度清洗、详情正文校验与舆情研报判断修复

本版本继续基于 V3.15 增量修复，不重写系统。

## 修复重点

1. 强化 `news_cleaner.valid_news_item`：新增股票专页栏目词黑名单，过滤“个股研报、主力持仓、现金流量表、公司资料、相关资料、研究报告、财务附注、上市公告”等单独栏目标题。
2. 新增菜单/表格残片识别：过滤 `href=、target=、stat=、menu:、padding-left、/600438/news/、stockid/、stockpage` 等残留片段。
3. 修复新浪/同花顺链接提取：优先使用 `title` 属性，跳过股票页栏目入口，不再把栏目菜单当新闻。
4. 新增普通新闻详情页正文二次校验：对新浪、同花顺、研报/新闻链接尝试读取详情正文，正文有效后重新计算事件类型、时间字段和情绪。
5. 修复同一公告重复展示：持久化库以 `event_key` 优先作为唯一键，并清理旧库中 event_key 相同但 duplicate_group 不同的重复行。
6. 舆情正负判断：社区/股吧/雪球不再强制中性，改为“正面舆情/负面舆情/中性舆情”，但仍不作为公司事实核心计分。
7. 研报观点判断：真实研报标题/正文可识别买入、推荐、上调目标价、下调评级、低于预期等方向；栏目入口仍被过滤。
8. 清洗日志聚合：相同来源和相同原因的丢弃项合并统计，减少控制台刷屏。
9. 分析缓存 key 升级为 `cn_v315_v16_1`，避免复用 V16 旧缓存中的污染结果。
