# V3.7 / InfoFix V8 技术指标矩阵改造说明

参考“量价时空”和技术指标分类思路，本版重点改造股票筛选模块：

1. 新增指标计算函数
   - ATR / KDJ / WR / CCI / ROC / MOM / OBV / MFI / VWAP / ADX / 支撑压力。
   - BOLL 增加带宽与价格位置。

2. 评分结构调整
   - 低位分：60/120/250日位置、回撤、低点反弹。
   - 趋势分：MA结构、斜率、MACD、BOLL中轨。
   - 动量分：RSI、KDJ、WR、CCI、ROC、MOM、MACD柱。
   - 量能分：成交额、换手率、量比、5/20日量能、涨跌与放量关系。
   - 波动空间分：ATR、BOLL带宽、箱体位置、支撑压力。
   - 资金强度分：VWAP、MFI、OBV、ADX/+DI/-DI、成交额方向。
   - 盘口行为分：盘尾强收估算、高换手、放量滞涨、缩量上涨等公开数据可估算信号。
   - 风险扣分：ST/退市、破位、放量下跌、异常量比、长期弱势等。

3. 标签解释修复
   - 新增动量、波动空间、资金强度类标签解释。
   - 展示当前数值、单位、判断含义，解决“标签解释无数据/全是空值”的问题。

4. 前端布局微调
   - 筛选结果表新增“动量、波动/空间、资金强度”列。
   - 右侧详情展示 KDJ、ATR%、BOLL宽度、VWAP、MFI、ADX、支撑压力等关键值。

5. 保留既有功能
   - 不删除 V3.6 的信息面、全球新闻、公司画像、评分历史、分时兜底、成交量累计转增量等功能。
