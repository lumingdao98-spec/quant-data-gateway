# V3.6 / InfoFix V7 更新说明

本版针对用户反馈继续修复：

1. 东方财富 quote 连接失败时不再反复刷屏；ProviderManager 仍会自动降级到新浪/腾讯/AKShare，并在 `/api/provider/warnings` 保留诊断。
2. 信息面改为“事件级去重 + 时效权重”：同一亏损、问询、减持、订单、回购等多源转载只计一次主权重；近30/90天权重更高，历史信息保留但降权。
3. 修正“虽盈利但承压/担忧”等标题：不再因为出现“盈利”就判为利好；带转折/担忧/低于预期时按中性偏谨慎处理。
4. 社区/股吧/传闻仅作为舆情观察，疑似假消息、网传、小作文自动高噪声降权。
5. 全球/国内要闻继续多源短缓存抓取，并按行业关键词映射到所选标的的政策/行业评分中。
6. ETF 没有公司简介时生成基金画像：ETF/场内基金类型、基金管理人、基金经理、跟踪指数等字段能抓到则入库。
7. 筛选评分新增盘口/量价行为估算：缩量/放量、换手状态、盘尾强收估算、短期急拉后洗盘风险、放量滞涨/疑似对倒需 Level-2 核验。
8. 标签解释补齐“量能平稳、大中市值、盘尾强收、妖股洗牌、对倒/虚假活跃”等标签，明确免费公开行情不能确定主力行为。

注意：主力持仓、虚假单、左手倒右手、精确抢筹等需要 Level-2、逐笔成交、席位/龙虎榜或券商数据。本系统只能基于公开行情做风险提示，不能当成事实结论。
