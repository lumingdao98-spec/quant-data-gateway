# V3.15 / InfoFix V16.3 三通道候选、50项技术矩阵、信息源有效证据扩展版

## 本版定位

本版不是继续“抓一堆再清洗”，而是把系统升级为：

1. 三通道候选池：换手率通道、成交额通道、技术初筛通道；
2. 三层评分框架：外层20%市场/情绪/板块，中层45%板块和资金连续性，底层35%量价技术/基本面雷点；
3. 50项以上技术/量价时空快照：量、价、时、空、情绪、形态、风控、盘口占位全部给出；
4. 信息面按“有效证据数”决定是否补充抓取，不再按原始抓取条数误判“够了”；
5. 专业财经门户作为结构化源不足时的补充，但百度/360/搜狗搜索结果页仍彻底禁用。

## 主要修改文件

- `quant_data/services/trading_framework_service.py`
  - 新增 50+ 技术/量价时空分析快照；
  - 新增 Tradercore 风格的三通道候选、20/45/35 三层诊断框架；
  - 输出“脚本结论 vs 人工复核”表格结构。

- `quant_data/services/screener_service.py`
  - 筛选池增加三通道候选排序；
  - `ScreenerResult` 新增 `indicator50_snapshot` 和 `tradercore_diagnosis`；
  - 技术面不再只是少量指标，而是保留完整 50+ 项快照。

- `quant_data/services/news_service.py`
  - 缓存 key 升级到 `cn_v315_v16_3`；
  - `_search_all` 改为按有效证据预估数扩展抓取；
  - 东方财富公告接口、巨潮公告全文检索增加分页；
  - 新增专业财经门户补充源：财联社、证券时报、中证网、上海证券报、每日经济新闻、第一财经；
  - 搜索引擎结果页仍不抓取、不展示、不计分。

- `quant_data/screener_ui.py`
  - 筛选页右侧显示 50 项技术快照覆盖情况；
  - 显示三通道/三层诊断，不展示长篇新闻；
  - 信息面详情仍通过独立入口打开。

- `tests/test_infofix_v16.py`
  - 新增 V16.3 测试：50项快照、三层权重、筛选结果字段、有效证据不足时继续补充抓取。

## 重要说明

`limit=180` 是目标上限，不代表所有外部公开源都一定能返回180条真实有效证据。如果一家上市公司近期真实公告/新闻有限，系统不会用菜单页、表格页、搜索页、小作文去凑数。V16.3 的改变是：当原始抓取很多但清洗后有效少时，会继续补充专业媒体和更多分页公告；最终仍以“有效证据”优先。
