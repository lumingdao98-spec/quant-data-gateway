# V3.13 / InfoFix V14 信息面抓取与前沿要闻评分重构

## 主要修复

1. 筛选页不再展开信息面明细、全球要闻、来源诊断和说明块，只保留“打开信息面分析详情页”入口。
2. 百度/360/搜狗等搜索结果页彻底禁用：不抓取、不计分、不展示。
3. 个股信息抓取由“关键词站内搜索”为主改为“公告/F10/个股资讯专页”为主：东方财富F10、东方财富公告、巨潮全文、Sina个股新闻页、同花顺个股资讯页。
4. 站内搜索仅在结构化源明显不足时少量兜底，避免控制台刷大量0条日志。
5. 增加金十/金十期货全球快讯抓取尝试：flash-api JSON + xnews/qihuo HTML摘要兜底；失败只记录诊断，不伪造数据。
6. 全球/前沿要闻短缓存继续保留，并按宏观、行业、国际、商品、政策映射到行业和产业链后进入信息面分。
7. 信息面分公式调整为：公司/公告30%、来源可信10%、财报估值16%、前沿要闻/行业映射36%、传闻噪声8%。
8. 筛选融合权重提高：默认35%，信息面融合/事件驱动策略45%，手动最高65%。
9. 增加股票行业暴露识别：对部分常见标的和行业关键词做本地暴露文本，解决“通威股份”这类名称不含“光伏/硅料”导致全球要闻无法映射的问题。
10. 行业映射规则补充：光伏、硅料价格、流动性宽松/收紧、原油、黄金、出口管制、AI芯片、新能源、地产、军工、医药等。

## 使用入口

筛选页：`http://127.0.0.1:8000/screener`

信息面详情页：`http://127.0.0.1:8000/info?symbol=600438&name=通威股份`

## 注意

公开站点接口可能变化或受网络环境影响，系统会在命令窗和详情页 sources_status 中显示诊断。系统不绕过登录、验证码和付费权限，不伪造新闻或Level-2数据。
