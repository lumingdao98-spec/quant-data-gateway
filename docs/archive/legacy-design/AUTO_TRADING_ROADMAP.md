# Auto Trading Roadmap

V3.21 仍是研究和 paper trading 阶段。真实自动交易之前必须通过以下验收。

## 已完成底座

- 科学历史回测：下一交易日成交、A 股执行约束、费用和滑点。
- 多仓位模式：固定仓位、等权、评分加权、波动率、ATR、定投、金字塔和核心-卫星。
- 三面评分融合：基本面、技术面、信息面和市场环境动态归一化。
- 异常波动和数据新鲜度：阻断 stale 数据、异常行情和信息面 veto。
- 实时 paper trading：信号、订单、风控、模拟成交、持仓和审计日志闭环。

## 进入真实券商前必须补齐

- 连续 paper trading 对照真实盘口，验证滑点、冲击成本和成交概率。
- 真实资金股份同步、委托回报、成交回报、撤单、重试和幂等。
- 人工确认队列和权限隔离，尤其是大额订单、异常波动和信息面事件。
- 交易日历、午休、集合竞价、停牌、涨跌停和临停的更严格处理。
- 审计日志落库、告警、异常停机和回滚策略。
- 真实券商 API 沙箱验收，不得复用研究 API 直接下单。

## 禁止事项

- 不得用当前新闻、当前财务或当前大盘环境回填历史回测。
- 不得伪造 Level-2 或五档盘口结论。
- 不得在数据 stale、行情源异常或风控未通过时自动交易。
- 不得把回测收益当作实盘收益承诺。
